# 浮気異変発見ゲーム

LINE風チャットと裏垢SNS風タイムラインを読み比べて、恋人の発言と投稿の矛盾を突きつけるターン制テキスト推理ゲームです。

## 遊び方

1. タイトル画面からキャラクターを選びます。
2. 各ターンでLINEメッセージと裏垢投稿を読み比べます。
3. 矛盾がある場合は、該当する裏垢投稿とLINE返信を選んで「突きつける」を押します。
4. 矛盾がない場合は「普通に返事する」を押します。
5. 証拠を3つ集めるとクリア、ゲージが0になるとゲームオーバーです。

## ファイル構成

- `index.html` - GitHub Pagesで配信するエントリーポイント
- `styles.css` - スマホ対応のゲームUIスタイル
- `src/app.js` - 画面遷移、ターン進行、正誤判定ロジック
- `data/scenarios.json` - キャラクター別シナリオ外部データ
- `manifest.webmanifest` / `sw.js` - PWA対応ファイル
- `assets/characters/` - キャラクター立ち絵、LINEアイコン、裏垢アイコン
- `assets/icons/` - PWAアイコン

## ローカル確認

静的ファイルだけで動作します。ローカルサーバーを起動して確認してください。

```bash
python3 -m http.server 8000
```

その後、<http://localhost:8000> を開きます。

## アセットについて

CodexのPR作成画面でバイナリファイルが扱えない環境でも差分確認できるように、同梱アセットはテキスト形式のSVGで管理しています。`data/scenarios.json` のアセットパスを書き換えれば、後からPNGなどの画像へ差し替えることもできます。
